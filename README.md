# Arceus Native Lab v0.1

Experimental Android XCI structure inspector. Does not run Nintendo Switch games and does not decrypt NCA content.

## Build
Upload repository files to GitHub, open Actions > Android APK > Run workflow, and download the APK artifact. Java 17 and Android SDK 35 are configured in workflow.

## Privacy
All reads occur locally through Android's file picker. Do not upload prod.keys or copyrighted game data to the repository.
